# Okazje — акции Lidl, Biedronka, Żabka, Kaufland

Личное мобильное приложение (Android и iOS) для отслеживания акций в польских супермаркетах.
Подстраивается под ваши предпочтения и присылает уведомления о самых выгодных предложениях.

## Что умеет

- **Для вас**: подборка «горячих» акций под ваши предпочтения, лучшие сверху.
- **Все акции**: поиск (по-польски: `kawa`, `masło`), фильтры по магазину и категории, сортировка
  по выгоде, скидке, цене и сроку окончания.
- **Предпочтения** (сохраняются на телефоне):
  - магазины;
  - любимые товары: о любой акции на них придёт уведомление;
  - любимые и скрытые категории (12 категорий определяются автоматически по польскому названию товара);
  - слова-исключения (например, `piwo`);
  - порог выгодности: скидка от 15/20/30/40/50 %;
  - учитывать ли акции, доступные только в приложении/по карте (Lidl Plus, Moja Biedronka, Żappka, Kaufland Card).
- **Уведомления**:
  - фоновая проверка примерно раз в 4 часа (точное время выбирает ОС);
  - одно сводное уведомление о *новых* выгодных акциях;
  - тихие часы: уведомление переносится на утро;
  - лимит уведомлений в день;
  - об акциях, которые вы уже видели в приложении, повторно не сообщается.
- Скидка считается и для механик вроде «1+1 gratis» (= 50 %) или «−50 % na drugi» (= 25 %).
- Карточка акции: срок действия, ссылка на сайт магазина, кнопка «следить за этим товаром».

## Запуск на телефоне

Нужен Node.js 20+.

```bash
npm install
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** (Android/iOS). Так удобно смотреть интерфейс, но фоновые
проверки в Expo Go работают ограниченно. Для полноценной работы соберите APK для Android:

```bash
npx eas-cli@latest build --platform android --profile preview
```

EAS соберёт APK в облаке (нужен бесплатный аккаунт Expo). Ссылку на файл откройте на телефоне и установите.

Чтобы посмотреть приложение без живых данных, включите в настройках **«Демо-данные вместо сайтов»**.

## Откуда берутся акции

У сетей нет публичного API, поэтому приложение само читает страницы с акциями
(`src/core/stores.ts`, адреса можно заменить в настройках) и достаёт из них данные о товарах
(`src/providers/extract.ts`):

1. JSON-LD (`schema.org/Product`);
2. встроенное состояние страницы (`__NEXT_DATA__`, `window.__NUXT__` и т. п.);
3. JSON в `data-*`-атрибутах (так Lidl отдаёт карточки товаров);
4. если ничего из этого нет — HTML-карточки товаров (`product-tile`, `price`, `old-price`…).

> ⚠️ Парсеры проверены на тестовых HTML-страницах, повторяющих структуру сайтов, но не на живых
> сайтах: из среды разработки они были недоступны. Если какая-то сеть показывает «ошибка» или
> 0 акций, в настройках видна причина. Можно указать другой адрес страницы с акциями, а если
> структура сайта отличается — дописать для этой сети свой разбор в `src/providers/`.

## Структура

```
src/
  app/                 экраны (expo-router): вкладки «Для вас», «Все акции», «Настройки», карточка акции
  core/                чистая логика без React Native (покрыта тестами)
    types.ts           модели Deal и Preferences, настройки по умолчанию
    stores.ts          магазины: цвета, сайты, адреса страниц с акциями
    categories.ts      определение категории по польскому названию
    price.ts           разбор цен, расчёт скидок (в т.ч. «1+1», «−50% na drugi»)
    scoring.ts         фильтрация и ранжирование под предпочтения, признак «горячая»
    notify.ts          что и когда уведомлять: новые акции, тихие часы, лимит в день
  providers/           загрузка и разбор страниц магазинов, демо-данные
  services/            хранилище (AsyncStorage), уведомления, фоновая задача
  state/               React-контекст с акциями и предпочтениями
__tests__/             тесты (jest) + HTML-фикстуры
```

## Разработка

```bash
npm test            # тесты
npm run typecheck   # TypeScript
npm run lint        # ESLint
npm run format      # Prettier
npm run web         # быстрый просмотр в браузере (только демо-данные: сайты магазинов блокируют CORS)
```

## Как добавить ещё одну сеть

1. Добавьте id в `StoreId` (`src/core/types.ts`) и описание в `STORES` (`src/core/stores.ts`):
   название, цвета, сайт, адреса страниц с акциями.
2. Если универсальный разбор не справляется, напишите для сети свою функцию в `src/providers/`
   и вызовите её в `fetchStore`.
3. Добавьте HTML-фикстуру и тест в `__tests__/extract.test.ts`.
