# Okazje — акции продуктовых сетей и магазинов электроники

Личное мобильное приложение (Android и iOS) для отслеживания акций в польских магазинах:
продукты — Lidl, Biedronka, Żabka, Kaufland; электроника — MediaMarkt, RTV Euro AGD, Media Expert, Neonet.
В настройках можно включить ещё 16 сетей: Aldi, Carrefour, Netto, Dino, Auchan, Intermarché, POLOmarket,
Stokrotka, Lewiatan, Rossmann, Hebe, Pepco, Action, Castorama, Leroy Merlin, OBI.
Подстраивается под ваши предпочтения и присылает уведомления о самых выгодных предложениях.

## Что умеет

**Акции**
- **Для вас**: подборка «горячих» акций под ваши предпочтения, лучшие сверху.
- **Все акции**: поиск, группы магазинов (продукты / электроника / дрогерии / дом), «★ Избранное»
  и единое окно **фильтров** — магазины, категории, цена от/до, «только с известной выгодой»,
  сортировка. Активные фильтры видны чипами, каждый снимается одним нажатием.
- **Разница цен на каждой акции**: экономия к обычной цене или средняя выгода механики «1+1»;
  сравнение с тем же товаром в других сетях (с учётом фасовки); прошлая цена в этом магазине;
  иначе — честная пометка «обычную цену магазин не указал».
- **Цена за кг / л** на карточке — сравнивает 250 г и 1 кг честно.
- **Карточка акции**: график истории цены, цены в других сетях, «📰 Показать в газетке» (страница
  газетки внутри приложения, товар обведён рамкой), «🎯 Следить за ценой», «+ в список», ★ в избранное.
- **📷 Сканер штрихкодов**: наведите камеру на товар в магазине — приложение узнает его по базе
  Open Food Facts (а также Open Beauty / Products Facts) и покажет, где он сейчас по акции и что есть похожего.

**Список покупок**
- Товары добавляются текстом, кнопкой «+ в список» или сканером. Для каждого выбирается самая дешёвая
  акция (по цене за кг/л, если известна фасовка), список разбит по магазинам.
- **Где покупать**: ограничение «не больше N магазинов» — приложение подберёт сочетание сетей с наименьшей
  суммой; «📍 Рядом» оставляет только сети, магазины которых есть в радиусе 1/2/5 км (OpenStreetMap).
- **Поделиться / Импорт**: список уходит текстом в любой мессенджер, а вставленный текст превращается
  в список — так удобно вести общий список с семьёй (настоящая синхронизация требует сервера).
- **Счётчик экономии** за месяц по купленным товарам.
- **Слежение за ценой**: «сообщить, когда товар будет не дороже X zł».

**Уведомления**
- фоновая проверка примерно раз в 4 часа; одно сводное уведомление о *новых* выгодных акциях;
- товар из списка или слежения появился в акции; акция из списка заканчивается завтра;
- тихие часы и лимит уведомлений в день.

**Прочее**
- **Виджет на главный экран Android** «🔥 Лучшие акции»: нажатие на строку открывает акцию.
  Добавляется как обычный виджет (долгое нажатие на рабочем столе → Виджеты → Okazje).
- Тёмная тема (по системной), режим «газетки только по Wi-Fi».
- Предпочтения: магазины, любимые товары и категории, слова-исключения, порог выгодности,
  акции только по приложению/карте.

## Установка на Android без компьютера (GitHub Actions)

Каждый push в репозиторий запускает сборку APK на серверах GitHub
(`.github/workflows/android-apk.yml`). Сборка занимает 15–25 минут. Сначала прогоняются тесты,
и если что-то сломано, APK не выпускается.

1. На телефоне откройте репозиторий на GitHub → **Releases** (или вкладку **Actions**, чтобы следить за сборкой).
2. Откройте последний релиз «Okazje — сборка N» и в разделе **Assets** скачайте `okazje-N.apk`.
3. Откройте файл и разрешите установку из этого источника. Если Play Protect предупредит, нажмите «Всё равно установить».
4. Новые сборки ставятся поверх старой: настройки сохраняются.

Пересобрать вручную без изменений в коде: **Actions → Android APK → Run workflow**.

APK собирается для arm64 (практически все современные телефоны) и подписан стандартным
отладочным ключом React Native. Для личного использования этого достаточно, но для публикации
в Google Play нужен собственный ключ.

## Запуск через Expo Go / EAS

Нужен Node.js 20+.

```bash
npm install
npx expo start
```

Отсканируйте QR-код приложением **Expo Go** (Android/iOS). Так удобно смотреть интерфейс, но фоновые
проверки в Expo Go работают ограниченно. Для полноценной работы соберите APK для Android:

```bash
npx eas-cli@latest build --platform android --profile preview
```

EAS соберёт APK в облаке (нужен бесплатный аккаунт Expo). Ссылку на файл откройте на телефоне и установите.

Чтобы посмотреть приложение без живых данных, включите в настройках **«Демо-данные вместо сайтов»**.

## Откуда берутся акции

Проверено на живых сайтах (октябрь 2026, `scripts/probe-sources.ts`):

| Сеть | Источник | Что есть |
|---|---|---|
| Lidl | газетки на blix.pl + главная lidl.pl | ~600 акций; у непродовольственных товаров с lidl.pl есть старая цена |
| Biedronka | газетки на blix.pl | ~1100 акций (сам biedronka.pl публикует акции только картинками) |
| Żabka | газетки на blix.pl + главная zabka.pl | ~570 акций; с zabka.pl — старая цена и отметка «Cena z Żappką» |
| Kaufland | газетки на blix.pl | ~1300 акций (kaufland.pl блокирует автоматические запросы проверкой Cloudflare) |
| MediaMarkt | газетки на blix.pl | ~20 акций (ТВ, бытовая техника, мониторы) |
| RTV Euro AGD, Media Expert, Neonet | газетки на blix.pl | появляются, когда сеть выпускает газетку |

Сайты магазинов электроники (Media Expert, x-kom, Neonet, Komputronik) закрыты проверкой Cloudflare,
у euro.com.pl акции подгружаются скриптом — поэтому электроника тоже берётся из газеток. x-kom газеток
не выпускает и пока не поддерживается.

[blix.pl](https://blix.pl) собирает газетки сетей и показывает каждую акцию с названием, акционной
ценой и сроком. Приложение берёт основные газетки (недельные, «od poniedziałku», «od czwartku»,
«festiwal…»), затем тематические, до 8 на сеть. Каждая газетка (до ~3 МБ) скачивается один раз и
хранится до конца срока, дальше обновляется только список газеток.

**Ограничение:** в газетках нет обычной цены, поэтому процент скидки известен только для части
товаров (lidl.pl, zabka.pl). Остальные акции попадают в «Для вас» и в уведомления через
**любимые товары**: добавьте в настройках, что вы обычно покупаете (`kawa`, `masło`, `kurczak`…).

Если сайт поменяется, загрузку можно проверить на живых данных: workflow **Probe shop pages**
запускается при каждом изменении кода разбора и печатает, сколько акций найдено по каждой сети;
с флагом `--pages` выводит структуру страниц для доработки разбора.

## Структура

```
src/
  app/                 экраны (expo-router): вкладки, карточка акции, газетка, сканер
  core/                чистая логика без React Native (покрыта тестами)
    types.ts           модели Deal и Preferences, настройки по умолчанию
    stores.ts          магазины: цвета, сайты, адреса страниц с акциями
    categories.ts      определение категории по польскому названию
    price.ts           разбор цен, расчёт скидок (в т.ч. «1+1», «−50% na drugi»)
    scoring.ts         фильтрация и ранжирование под предпочтения, признак «горячая»
    compare.ts         сравнение цен между сетями, история цен, пояснение к цене
    filter.ts          фильтры и сортировка вкладки «Все акции»
    shoppingList.ts    список покупок: подбор самой дешёвой акции и разбивка по магазинам
    notify.ts          что и когда уведомлять: новые акции, тихие часы, лимит в день
    alerts.ts          уведомления по списку и слежению за ценой
    units.ts           фасовка и цена за кг/л
    nearby.ts          магазины рядом (OpenStreetMap / Overpass)
    barcode.ts         штрихкоды и поиск отсканированного товара в акциях
    widget.ts          строки виджета
  providers/           загрузка: blix.ts (газетки), zabka.ts, extract.ts (универсальный разбор), products.ts (Open Food Facts), демо-данные
  widget/              виджет Android (react-native-android-widget)
  services/            хранилище (AsyncStorage), уведомления, фоновая задача
  state/               React-контекст с акциями и предпочтениями
__tests__/             тесты (jest) + HTML-фикстуры
```

## Разработка

```bash
npm test            # тесты
npm run typecheck   # TypeScript
npm run lint        # ESLint
npm run format      # Prettier
npm run web         # быстрый просмотр в браузере (только демо-данные: сайты магазинов блокируют CORS)
```

## Как добавить ещё одну сеть

1. Добавьте id в `StoreId` (`src/core/types.ts`) и описание в `STORES` (`src/core/stores.ts`):
   название, цвета, сайт, адреса страниц с акциями.
2. Если универсальный разбор не справляется, напишите для сети свою функцию в `src/providers/`
   и вызовите её в `fetchStore`.
3. Добавьте HTML-фикстуру и тест в `__tests__/extract.test.ts`.
