# Фокус — уведомления не отвлекают, звонки проходят

Мини-приложение для Android: одна большая кнопка включает «фокус», и уведомления из выбранных
приложений перестают отвлекать. **Звонки проходят всегда** — и обычные, и звонки в мессенджерах.

## Что умеет

- **Одна кнопка** «Включить фокус» и длительность одним касанием: 25 мин, 1 час, 2 часа или «пока не выключу».
- **Плитка «Фокус» в шторке** (быстрые настройки): включить и выключить, не открывая приложение.
  На Android 13+ кнопка «Добавить плитку» добавляет её сама.
- **Что скрывать — одним касанием**: 💬 мессенджеры, 📱 соцсети и видео, ✉️ почта, 🛒 покупки и реклама,
  🎮 игры, 📨 SMS, 📦 всё остальное. По умолчанию SMS не скрываются (коды из банка).
- **Отдельные приложения**: касание по приложению переключает «скрывать / пропускать» независимо от группы
  (например, скрыть все мессенджеры, кроме рабочего Slack).
- **🔇 Тишина для остального**: включает «Не беспокоить» так, что звонят только звонки (от всех, контактов
  или избранных; повторный звонок за 15 минут проходит) и будильники. Остальное приходит без звука.
- **Пропущенное**: всё скрытое сохраняется списком по приложениям — ничего не теряется. Касание «Открыть»
  переводит в приложение. По окончании фокуса приходит итог: «Фокус закончился · скрыто 12: Telegram 7…».
- Никогда не скрываются: звонки и пропущенные звонки, будильники, напоминания календаря, навигация,
  музыка и другие постоянные уведомления.

## Установка

Каждый push с изменениями в `focus/` собирает APK на GitHub (workflow **Fokus APK**, 15–25 минут).
На телефоне: репозиторий → **Releases** → «Фокус — сборка N» → скачайте `fokus-N.apk` и установите.

### Первый запуск (один раз)

1. Нажмите «Включить фокус» → откроется «Доступ к уведомлениям» → включите «Фокус».
2. **Если переключатель серый** (Android 13+ так защищает приложения, скачанные не из Play Маркета):
   Настройки → Приложения → Фокус → ⋮ вверху справа → «Разрешить ограниченные настройки», и снова шаг 1.
3. Для режима «Тишина» включите «Фокус» в «Доступ к режиму Не беспокоить» (приложение покажет кнопку,
   если это нужно; на многих телефонах доступ даётся вместе с шагом 1).
4. «Добавить плитку» — и дальше фокус включается из шторки одним касанием.

## Как это устроено

- `modules/fokus/` — локальный Expo-модуль на Kotlin:
  - `FocusListenerService` — служба доступа к уведомлениям: во время фокуса убирает уведомления
    выбранных приложений и записывает их в «Пропущенное»;
  - `FocusRules` — правила: к какой группе относится приложение, что не трогать никогда;
  - `FocusStore` — состояние и настройки (SharedPreferences), «Не беспокоить», таймер, итоговое уведомление;
  - `FocusTileService` — плитка в шторке; `FocusAlarmReceiver` — окончание по таймеру.
- `src/app/index.tsx` — экран; `src/core/focus.ts` — логика выбора (покрыта тестами).

iOS не поддерживается: iPhone не даёт сторонним приложениям скрывать чужие уведомления или включать
режим фокуса — это делается в Настройках → Фокусирование.

```bash
cd focus
npm install
npm test && npm run typecheck && npm run lint
```
