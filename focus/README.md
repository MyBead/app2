# Фокус — уведомления не отвлекают, звонки проходят

Мини-приложение для Android: одна большая кнопка включает «фокус», и уведомления из выбранных
приложений перестают отвлекать. **Звонки проходят всегда** — и обычные, и звонки в мессенджерах.

## Что умеет

- **Одна кнопка** «Включить фокус» и длительность одним касанием: 25 мин, 1 час, 2 часа или «пока не выключу».
- **Плитка «Фокус» в шторке**: включить и выключить, не открывая приложение (на Android 13+ кнопка
  «Добавить плитку» добавляет её сама).
- **📞 Звонки проходят всегда** — от всех, только от контактов или избранных; повторный звонок за 15 минут проходит.
- **Что блокировать — одним касанием**: соцсети, почта, игры, магазины и прочее блокируются всегда; чипами
  выбирается остальное — 💬 сообщения и мессенджеры, ⭐ важные чаты, 📅 напоминания и календарь,
  ⏰ будильники, 🎵 звук видео и музыки.
- **Как блокировать**: «Скрыть совсем» (ни звука, ни значка, ни строки в шторке — всё появится после фокуса)
  или «Только без звука».

Работает через режим «Не беспокоить» и требует только разрешения «Доступ к режиму Не беспокоить» — его Android
не ограничивает для приложений, установленных не из Play Маркета (на Android 15+ ограничены доступ к уведомлениям,
спец. возможности, «поверх других приложений» и статистика использования; см. `EnhancedConfirmationService` в AOSP).

### Разблокировка (по желанию): Shorts и выбор отдельных приложений

Эти функции используют доступ к уведомлениям и спец. возможности. Если телефон не показывает пункт
«Разрешить ограниченные настройки», запрет снимается один раз через беспроводную отладку, без компьютера:

1. «Для разработчиков» → «Отладка по Wi‑Fi».
2. [aShell You](https://github.com/DP-Hridayan/aShellYou) → подключиться по беспроводной отладке.
3. Выполнить `appops set pl.fokus.app ACCESS_RESTRICTED_SETTINGS allow`.
4. Включить «Фокус» в «Доступе к уведомлениям» и «Фокус: без Shorts» в спец. возможностях.

После этого появляются:
- **▶️ Без YouTube Shorts**: Shorts закрываются сразу, как только открылись (вкладка Shorts, лента, ссылка) —
  всегда или только во время фокуса. Служба получает события только от YouTube. Распознавание по id экрана
  Shorts (`reel_player_page_container`, `reel_progress_bar`) — тот же признак, что у открытых блокировщиков
  [Scrolless](https://github.com/duartebarbosadev/Scrolless) и
  [Shorts-Blocker](https://github.com/atick-faisal/Shorts-Blocker).
- **Группы и отдельные приложения**: скрывать мессенджеры, соцсети, почту… или конкретные приложения,
  со списком «Пропущенное» и итогом после фокуса.

## Установка

Каждый push с изменениями в `focus/` собирает APK на GitHub (workflow **Fokus APK**, 15–25 минут).
На телефоне: репозиторий → **Releases** → «Фокус — сборка N» → скачайте `fokus-N.apk` и установите.
При первом запуске нажмите «Открыть» в подсказке и включите «Фокус» в «Доступе к режиму Не беспокоить».

## Как это устроено

- `modules/fokus/` — локальный Expo-модуль на Kotlin:
  - `FocusListenerService` — служба доступа к уведомлениям: во время фокуса убирает уведомления
    выбранных приложений и записывает их в «Пропущенное»;
  - `FocusRules` — правила: к какой группе относится приложение, что не трогать никогда;
  - `FocusStore` — состояние и настройки (SharedPreferences), «Не беспокоить», таймер, итоговое уведомление;
  - `FocusTileService` — плитка в шторке; `FocusAlarmReceiver` — окончание по таймеру.
- `src/app/index.tsx` — экран; `src/core/focus.ts` — логика выбора (покрыта тестами).

iOS не поддерживается: iPhone не даёт сторонним приложениям скрывать чужие уведомления или включать
режим фокуса — это делается в Настройках → Фокусирование.

```bash
cd focus
npm install
npm test && npm run typecheck && npm run lint
```
